🎬 Movie App
A movie browsing application developed with Swift and UIKit, using the TMDB API to fetch and display real-time movie data.
✨ Features
🎬 Browse popular movies
🔍 Search for movies
⭐ Display movie ratings
📅 Display release dates
🖼️ Load movie posters dynamically
📖 View detailed movie information
🌐 Fetch data from the TMDB REST API
🛠️ Technologies
Swift
UIKit
TMDB API
REST API
JSON / Codable
SDWebImage
UITableView
Storyboard
Git & GitHub

🔐 API Key
The TMDB API key is intentionally excluded from this repository for security reasons.
To run the project locally, add your own API key to APIManager.swift.
🚀 Getting Started
Clone the repository.
Open the project in Xcode.
Add your TMDB API key to APIManager.swift.
Build and run the project on an iOS simulator or device.
