🎬 Movie App

A movie discovery iOS application built with Swift and UIKit using the TMDB API to fetch real-time movie data.

The app allows users to browse movies, search for specific titles, view ratings and release dates, and explore detailed movie information.

📱 Features
🎥 Browse popular and recent movies
🔍 Search for movies
⭐ Display movie ratings
📅 Display release dates
🖼️ Load movie posters dynamically
📖 View detailed movie information
🌐 Fetch real-time data from the TMDB API
⚡ Asynchronous image loading with SDWebImage

🔌 API

Movie data is provided by The Movie Database (TMDB) API.

The application retrieves information such as:

Movie title
Poster image
Rating
Release date
Overview
Other movie details

An API key is required to use the TMDB API.
